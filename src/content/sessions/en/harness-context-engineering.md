How to design the harness around a coding agent: tool selection, memory and orchestration. The amount of context you inject is just one lever, and more of it can make results worse.

The aim goes beyond staying effective over time: it is to put together all the tasks that let the agent reach its objective cheaply, quickly and with a low error rate.

The talk also covers the AI factory, meaning all the tooling to ship with AI, AI code review and spec-driven development, where the spec drives the agent and serves as the reference for reviewing its code.
